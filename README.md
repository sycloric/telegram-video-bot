# Telegram Video Bot

Бот для автоматической вставки рекламного ролика в середину отправленных пользователями видео.
Бот использует FFmpeg для обработки видео, поддерживает очередь задач, обрабатывает видео корректно, сохраняя аудио. В месте вставки делается freeze-frame (зависание видео) на настраиваемое время.

## Требования

- Python 3.12+
- FFmpeg (и ffprobe) должны быть установлены и доступны в PATH.

## Установка и запуск (Локально)

1. Клонируйте репозиторий:
   ```bash
   git clone <URL>
   cd telegram_video_bot
   ```

2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Установите FFmpeg:
   - **Windows:** Скачайте с официального сайта и добавьте путь к `bin` в системную переменную `PATH`.
   - **Linux (Ubuntu/Debian):** `sudo apt update && sudo apt install ffmpeg`
   - **macOS:** `brew install ffmpeg`

4. Настройка окружения:
   Скопируйте файл конфигурации:
   ```bash
   cp .env.example .env
   ```
   Отредактируйте `.env`:
   - `BOT_TOKEN` — ваш токен Telegram бота.
   - `AD_VIDEO_PATH` — путь к рекламному ролику с хромакеем.
   - `FREEZE_DURATION` — длительность паузы (зависания) перед началом рекламы (в секундах). Во время самой рекламы фон также будет заморожен.
   - `CHROMA_KEY_COLOR` — цвет фона, который нужно удалить (по умолчанию `0x00ff00`).
   - `CHROMA_SIMILARITY` — строгость удаления цвета (по умолчанию `0.25`).
   - `CHROMA_BLEND` — плавность/полупрозрачность краёв (по умолчанию `0.1`).
   - `AD_SCALE` — масштаб рекламного объекта от `0.1` до `1.0` (по умолчанию `1.0`).
   - `AD_POSITION_X` — позиция рекламы по X: `center`, `left`, `right` или математическое выражение (по умолчанию `center`).
   - `AD_POSITION_Y` — позиция рекламы по Y: `center`, `top`, `bottom` или математическое выражение (по умолчанию `center`).

5. Подготовка рекламного ролика:
   Поместите ваш рекламный ролик по пути, указанному в `AD_VIDEO_PATH` (по умолчанию `assets/advertisement.mp4`).

6. Запуск:
   ```bash
   python main.py
   ```

## Запуск в Docker

1. Создайте `.env` файл на основе `.env.example` и укажите там ваш `BOT_TOKEN`.
2. Поместите рекламное видео в папку `assets`.
3. Соберите и запустите контейнер:
   ```bash
   docker build -t telegram_video_bot .
   docker run -d --name video_bot --env-file .env -v $(pwd)/assets:/app/assets telegram_video_bot
   ```

## Известные ограничения
- Максимальный размер загружаемого видео в Telegram для ботов (без использования локального Bot API сервера) ограничен 20 МБ. Для работы с большими файлами вам потребуется настроить локальный Telegram Bot API Server и указать его в настройках aiogram.
- Большие видео могут обрабатываться медленно из-за полного перекодирования.
